# CRM: повторы клиентов, закрепление и импорт базы

Целевые правила 27.10.2026. Их уточнили и реализовали решения 28–29.10.2026
([links-contract.md](links-contract.md), пп. 9–13б) и выпуски П2а и П5; договор
кода — умение, [crm-duplicates-and-triage.md](https://github.com/skeeks-cms/skeeks-cms-package-development/blob/main/references/crm-duplicates-and-triage.md)
и [mailing-campaigns.md](https://github.com/skeeks-cms/skeeks-cms-package-development/blob/main/references/mailing-campaigns.md).

Целевые правила от 27.10.2026, реализация не начата. Заменяют прежнее решение
от 26.10.2026 «лид только для нового клиента». Здесь «сделка» — продажная
сделка на основе нынешнего `CmsLead`, «услуга» — нынешний `CmsDeal`.

**Два вида повторов.** Компания/человек — постоянная карточка; сделок у них
может быть несколько. Отдельно проверять повтор клиента и повтор конкретного
обращения. Новая потребность существующего клиента разрешает новую сделку;
продолжение того же открытого обсуждения относится к существующей. Закрытую
попытку не переоткрывать автоматически из-за попадания контакта в рассылку.

**Общая проверка по базе.** Email, телефон, ИНН, домен и название используются
для поиска кандидатов, включая недоступные сотруднику записи. Название и
совпадение отдельных контактов не являются безусловным основанием слияния.
Одна операция проверки используется формами, импортом и API; проверка не
выдаёт права чтения чужой карточки. Неизвестное обращение можно принять с
контактом без выдуманной компании; связь уточняется при разборе.

**Недоступный клиент.** Показывать минимальный ответ «Такой клиент уже есть,
ответственный …», без чужих контактов, переписки и сумм. Действия — запросить
доступ/передачу, отказаться или указать «Это другая компания» с причиной и
отметкой возможного дубля. Объединение доступно уполномоченному сотруднику,
с сохранением истории, связей, согласий и запретов и записью результата.

**Ответственность.** По умолчанию новую сделку получает ответственный компании,
инициатор сохраняется отдельно. Можно поручить другому менеджеру конкретную
сделку без передачи всей компании; ему доступны только явно разрешённые
контакты и материалы этой продажи. Это права сотрудников, не роли клиента
У1–У2. Неотработанная сделка может возвращаться ответственному компании или
руководителю по настраиваемому сроку (общего пула нет, п. 13а); действующий клиент с обслуживанием автоматически не освобождается
только из-за отсутствия новых продаж. Точные сроки задать при реализации.

**Импорт холодной базы и заявок.** Не создавать отдельную сущность человека
поверх существующих контактов; выбрать существующую карточку или создать
компанию/контакт с источником и состоянием обработки. Холодная база — аудитория,
а не скрытая стадия продажной сделки. Конкретное хранение состояния аудитории
уточнить на П1; текущий `LeadImport` сам по себе пока не реализует этот план.

| Нашли / получили | Целевое действие |
|---|---|
| Действующий клиент | Использовать существующую карточку; не включать автоматически в холодную аудиторию; допродажи — отдельная подходящая аудитория |
| Бывший клиент, партнёр, поставщик | Использовать существующую компанию/контакт, сегментировать и проверить допустимость обращения |
| Открытая сделка по тому же запросу | Дополнить её, не создавать повтор; учитывать текущую работу менеджера при рассылке |
| Отказ с действующей паузой или запрет контакта | Исключить в соответствующей теме/канале/сроке; импорт не снимает ограничений |
| Давний отказ | При допустимости включить контакт в аудиторию; закрытую сделку не переоткрывать; новый интерес — новая попытка продажи |
| Новый холодный контакт | Создать/уточнить карточку контакта или компании, источник и состояние аудитории; сделку не создавать |
| Импорт реальной заявки или подтверждённый новый интерес | Найти клиента и повтор запроса, затем создать сделку либо дополнить открытую |

Отклик для новой сделки — конкретный интерес: ответ, заявка, просьба связаться,
подтверждённая потребность в разговоре. Менеджер также может явно начать работу
над конкретной продажей. Открытие письма, переход и просмотр презентации —
сигналы, они сами сделку не создают; задача связаться может остаться отдельным
правилом. Поддержка по действующей услуге становится задачей, не продажей.

**Отказ и паузы.** «Не сейчас» — пауза по потребности до даты; «эта услуга не
нужна» — ограничение по теме; «не пишите» — запрет рекламных обращений по
соответствующему контакту/каналу. Причина отказа не должна автоматически
блокировать все услуги клиента на один общий срок. Согласия и отписки остаются
у контакта и проверяются общим механизмом коммуникаций.
