# План направления «Хостинг»

Пакет: `cms-hosting` (закрытый репозиторий). Услуги хостинга продаются через
услуги CRM (`CmsDeal`): у каждой своя цена и срок, ресурсы услуги (сайт, VPS,
DNS-зона, SSL-сертификат) принадлежат ровно одной услуге — см.
[crm/deal-as-service.md](../crm/deal-as-service.md).

| Файл | Что в нём |
|---|---|
| [domains.md](domains.md) | Продажа доменных имён через API регистратора (reg.ru): решения, модель, этапы |

Услуги DNS, SSL, мониторинг и почта уже работают; отдельного плана по ним
пока нет, устройство — в документах пакета `cms-hosting`.
