# Товарная база ↔ сайт хостинга: ключ API без ручной правки сервера

Студия держит сайты клиентов на своих серверах и не даёт клиентам FTP. Сайты,
получающие товары поставщиков (skeeks-market), читают ключ товарной базы из
`config/common/params.php` (`skeeksSuppliersApi.api_key`, компонент магазина).
Раньше ключ копировали из карточки базы и вписывали на сервере вручную.

## Решения владельца — 25.11.2026

- Связь хранится у товарной базы (код проекта skeeks.com): поле «сайт хостинга»,
  уникальное — у базы не больше одного сайта, у сайта не больше одной базы.
- Ключ пишется точечной правкой `params.php` (вариант А): работает на всех сайтах
  сразу, без обновления пакетов. Отдельный файл с ключом, который читает сам
  пакет магазина, — возможный второй этап (нужен выпуск пакета магазина и
  обновление сайтов поставщиков).
- Перед записью — резервная копия, проверка синтаксиса и чтения значения; при
  ошибке файл возвращается. Нестандартный файл не трогаем: база подключается,
  сотрудник видит, что вписать вручную, и потом нажимает «Проверить ключ».
- Выбор сайта — только сайты того же клиента (компании или частного лица
  услуги базы), доступные сотруднику; действовать с сайтом — по тем же правам,
  что смена домена и SSL.
- Запись выполняется сразу по нажатию (несколько секунд), без очереди.
- После записи обработчики очередей сайта мягко перезапускаются, чтобы новый
  ключ подхватился сразу.
- Уже вписанные вручную ключи: связи сопоставляются по названию базы и
  домену сайта консольной командой; проверка ключей на серверах (только
  чтение) — отдельно, после «да» владельца.

## Отвязка — решение владельца 25.11.2026

- Обычная отвязка удаляет из настроек сайта любой непустой ключ
  `skeeksSuppliersApi.api_key` — свой или вписанный вручную; ключ базы в CRM для
  этого не нужен. Пустое значение остаётся в файле без изменений. Заменяет
  правило того же дня «чужой ключ не трогаем».
- «Отвязать без правки сервера» меняет только CRM.
- Подключение и отвязка одной базы не выполняются одновременно; при потере
  ответа сервера связь остаётся со статусом «требуется сверка».

## Устройство

- Общая правка одного значения в настройках сайта — пакет `cms-hosting`
  (`SITE-PARAMS.md`): пакет не знает, что это ключ поставщиков.
- Связь, права, интерфейс — проект skeeks.com: меню «Сайт …» под названием
  базы (подключить, проверить, отвязать, отвязать без правки сервера),
  строка на вкладке «API», колонка «Сайт» в списке баз, строка «Товарная база»
  в карточке сайта (место для блоков других разделов в карточке сайта).
